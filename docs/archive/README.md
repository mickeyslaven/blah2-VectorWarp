# Historical records

This directory is the navigation point for historical evidence retained in the
repository. These records are immutable context for investigations and release
decisions, not current install, operating, configuration, or capability
instructions. Current user guidance is indexed in the [documentation map](../README.md).

The historical records remain at their established paths so published links and
evidence references stay valid. Date-stamped and explicitly historical files
in the documentation root are therefore part of this archive even when their
original path predates this index.
