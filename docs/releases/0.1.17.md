# VectorWarp 0.1.17

This release expands VectorWarp's coherent-array and GPU-resident processing while
keeping existing configurations compatible.

## Highlights

- Adds calibrated coherent surveillance beam banks for multi-channel Kraken arrays.
  The beam bank removes the measured per-channel complex response before steering;
  the existing noncoherent fusion path remains available.
- Adds GPU-resident two-CPI power integration without changing the 500 ms publication
  cadence or the public Retina track format.
- Adds independent controls for effective beam trials, a bounded direct-path null,
  limited inter-CPI motion search, and coherent-beam track association. They are
  optional and preserve established behavior by default.
- Carries winning-beam metadata through detection and tracker history while keeping
  public JSON compatible.
- Bounds GPU tracker capacity and adds deterministic admission/recovery behavior for
  overload conditions.
- Improves missing-receiver startup handling and suppresses incomplete first-frame
  detections when multi-CPI integration is enabled.
- Describes every new setting in the browser and validates it through the same
  save, recovery and receiver-start paths as existing settings.

## Validation

- CPU/API/replay suites pass on Linux x86-64 and ARM64.
- Native Kraken simulations pass on Linux x86-64 and ARM64.
- macOS CPU, open-receiver and standalone-runtime suites pass on Apple Silicon and Intel runners.
- All eleven DEB/RPM targets pass native build and installed-package smoke tests.
- A five-channel Fedora 44 deployment remained below its 500 ms CPI in the retained
  12-beam/two-CPI configuration, with flat steady-state drop counters and safe tracker capacity.

## Scope

Coherent beamforming improves spatial use of an array but does not guarantee more
physical antenna gain than a directional antenna. Beam identity is useful association
evidence, not a unique direction or aircraft position. Direct-path nulling, motion
search and beam-gated tracking should be enabled only after controlled measurements
on the installed array.
