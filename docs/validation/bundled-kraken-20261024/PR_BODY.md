Linux production builds previously depended on separately installed Heimdall, while macOS built a pinned companion. This change shares pinned sources and patches across native Linux/macOS builds, records hashed provenance and a source-component SBOM, adds an owned local service, and repairs watchdog/config-guard imports from their stable installed paths.

The upstream patch stamps reference-channel sample/transfer counters and host MONOTONIC_RAW/TAI/REALTIME anchors at Heimdall's first RTL callback. An opt-in versioned MCHT extension carries those values through the exact buffers; VectorWarp and the gain/shadow/raw readers accept it while retaining MCHQ compatibility. Gap/retune/reorder boundaries reset continuity. Cropped clips retain the original USB anchor sample. Missing PPS/TAI does not block coherent provisional capture, and host timestamps never become ADC hardware UTC or decision-grade evidence.

Validation: native macOS arm64 and Fedora 44 x86_64 companion builds; 7-scenario real-Heimdall/fake-RTL simulations on both; recording/socket/clip suite 7/7 on each; API timing/ownership/gain/watchdog 22/22; Fedora installer regressions 18/18 and raw capture 4/4; controller 10/10; upstream deterministic oracles. Evidence and reproduction commands are in `docs/validation/bundled-kraken-20261024/README.md`. No live RF or installed services changed.

The upstream no-binary-redistribution contract is preserved: DEB/RPM packages strip Heimdall/private driver/upstream assets and ship only our pinned source-build instructions and patches. Explicit `vectorwarp build-kraken` downloads checksum-pinned sources and compiles under a dedicated restricted non-radio account. Bounded, descendant-reaped compilation publishes checked regular files into root-owned immutable kit-keyed generations. Failed builds retain the old generation; package rollback selects its exact kit, never ambient Heimdall. Ordinary startup does not download/build software. Review upstream terms before requesting a local build.
