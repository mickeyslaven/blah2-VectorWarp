# Advanced and research material

This page collects work that is useful for evaluation or development but is not
part of VectorWarp's supported production capability statement. Do not use it
as an installation or operational-readiness guide.

- [Open Passive Radar Scorecard](PASSIVE_RADAR_SCORECARD.md) and its
  [runbook](OPRS_RUNBOOK.md) describe an independent evidence contract.
- [Bearing and bistatic geolocation](BEARING_GEOLOCATION.md) describes an
  experimental, opt-in array-research path. It is disabled by default and needs
  site-specific evidence before any operational conclusion.
- [External tracker shadow](EXTERNAL_TRACKER_SHADOW.md) and
  [track-guided shadow detector](TRACK_GUIDED_SHADOW.md) describe non-authoritative
  comparison paths; they do not change the supported detector or tracker.

For supported installation and receiver setup, return to [Install VectorWarp](INSTALL.md)
and [Receiver setup](SETUP.md).
